# 지하 7층의 종말 편의점

좀비 사태가 터진 폐허 도시의 지하 7층. 불이 꺼지지 않은 작은 편의점에 생존자들이 모여듭니다.
탐사대를 지상으로 보내 멸망 전 문명의 흔적(통조림, 건전지, 낡은 만화책…)을 주워 오고, 선반을 채우고, 개성 있는 생존자들을 맞이하는 **방치형 수집 게임**입니다.

(TypeScript + Vite, 화면은 캔버스 도트 장면 + HTML UI, 규칙은 `src/state.ts`)

## 게임 루프

1. **탐사** – 구역(슈퍼마트, 약국, 헌책방, 전자상가, 병원, 경찰서, 대형마트 지하)에 1~3명을 보냅니다. 시간이 지나면 배낭을 메고 돌아옵니다. 접속을 끄고 있어도 시간은 흐릅니다.
2. **수집** – 물건 43종(흔함/쓸만함/희귀/전설)이 선반에 진열됩니다. 진열된 물건은 분당 뚜껑(●)을 벌어 줍니다. 분류를 모두 채우면 +25%, 전부 채우면 ×1.5.
3. **영입** – 조건을 채우면 생존자가 문을 두드립니다. 각자 고유한 방치 버프와 3장짜리 개인 이야기를 갖고 있고, 대화·선물로 호감도를 올리면 이야기가 열립니다.
4. **개조** – 뚜껑으로 선반, 배낭, 안테나, 발전기를 개조합니다.

생존자의 버프는 **매장에 있을 때**(수입) 또는 **탐사대에 있을 때**(전리품·안전) 적용됩니다. 누구를 내보낼지가 선택입니다.

| 생존자 | 한 줄 | 버프 |
|---|---|---|
| 한송이 | 전직 해장국집 사장 | 매장: 식료품 수입 +40% |
| 서하준 | 밤샘 코딩하던 개발자 | 매장: 전자기기 수입 +40% |
| 오철민 | 은퇴한 특수부대 원사 | 탐사: 들킬 확률 -60%, 전리품 +1 |
| 나비 | 길고양이 | 탐사: 희귀·전설 확률 +80% |
| 정유나 | 종합병원 야간 간호사 | 매장: 의약품 수입 +40% |
| 박만복 | 40년차 만화방 주인 | 매장: 문화 수입 +40% |
| 강새벽 | 심야 라디오 DJ | 매장: 전체 수입 +10% |
| 두리 | 아홉 살 | 탐사: 전리품 +1, 새 발견 보너스 2배 |

좀비에게 들키면 전리품이 절반이 되고 탐사대가 잠시 지칩니다. 사망은 없습니다(따뜻한 톤).

## 구조

- `src/data.ts` : 물건, 구역, 생존자(이야기 포함), 개조 데이터
- `src/state.ts` : 규칙(수입, 탐사, 영입, 호감도, 저장). 화면과 무관하게 node 로 테스트 가능
- `src/shapes.ts`, `src/sprites.ts` : 코드로 그린 8x8 물건 아이콘, 생존자/좀비/고양이 도트
- `src/scene.ts` : 지상 + 지하 7층 편의점 단면 캔버스
- `src/ui.ts`, `src/style.css` : 탭(벙커/탐사/선반/생존자), 모달, 알림
- `tools/tests/logic.test.ts` : 규칙 테스트
- `legacy/` : 이전 방향(CRT 단말기 하드코어 생존 경영)의 그림 자산. 배포에는 포함되지 않음 (옛 코드는 git 기록에 남아 있음)

## 실행

```
npm install
npm run dev
npm test          # node 22.18+ (타입 제거 내장)
```

## 시험용

- 주소 끝에 `?speed=30` : 시간이 30배 빨라집니다 (탐사·방문자 등).
- 주소 끝에 `?reset` : 저장 삭제.
- 저장은 브라우저 localStorage 에만 됩니다.

## 그림 교체

지금 그림은 전부 코드로 그린 임시 도트입니다. 물건 모양은 `src/shapes.ts`(글자 8x8), 색은 `src/data.ts`의 팔레트, 사람은 `Look`(피부·머리·옷·장신구)으로 정해집니다.
나중에 그린 그림으로 바꿀 때는 `sprites.ts`의 `iconCanvas`/`drawPerson` 만 이미지 기반으로 교체하면 됩니다.

## 주의

- 모든 수치(수입, 개조 비용, 탐사 시간)는 **시험용**입니다. 밸런스는 미확정입니다.
- 폰트는 Galmuri(CDN)를 쓰며, 불러오지 못하면 시스템 글꼴로 보입니다.

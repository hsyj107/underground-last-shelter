# UNDERGROUND: LAST SHELTER

좀비 아포칼립스 지하 벙커 생존 경영 시뮬레이션. 플레이어는 단말기 앞의 사령관이며, 자원과 사람을 통제합니다.
(TypeScript + Vite, 화면은 HTML 단말기 UI, 규칙은 `src/sim` 의 순수 시뮬레이션 엔진)

## 구조
- `src/sim` : 게임 규칙(하루 정산, 배급, 원정, 세럼 결정, 칭호 등). 화면과 무관하게 테스트 가능
- `src/ui` : CRT 단말기 화면
- `tools/tests/sim.test.ts` : 엔진 테스트

## 실행
```
npm install
npm run dev
```

## 림월드식 시스템 (src/sim)

- `mind.ts` 기분: 스트레스는 "생각 목록"의 합이 가리키는 목표로 움직입니다. 관계(친구·앙숙), 죽음의 충격, 정신 붕괴(넋 나감·사재기·난동·살인).
- `story.ts` 이야기꾼: 형편이 좋으면 습격이, 어려우면 상인·보급·방랑자가 늘어납니다. 습격·상인·방랑자·다툼은 선택지를 고르면 진행됩니다.
- `body.ts` 몸: 부위별 부상, 후유증, 결손, 공방(Lv.2)에서 의수·의족 제작.
- 작업 우선순위: 생존자마다 시설별 1~4순위(또는 안 함)를 정하면 자동 배치됩니다. 직접 배치하면 그 인원만 수동으로 바뀝니다.
- 모든 수치는 시험용입니다.

## 시간
- 현실 시간이 흐르면 게임 하루가 자동으로 정산됩니다. (⚠ 임시: 현실 1시간 = 게임 1일)
- 접속하지 않은 동안은 최대 6일까지 한꺼번에 계산하고, 돌아오면 복귀 보고가 뜹니다.
- 시험하려면 주소 끝에 `?dayms=30000`(하루 30초)을 붙이거나, 화면 아래 "시험용" 버튼으로 하루를 즉시 넘깁니다.
- 정착지가 전멸하거나 폭동으로 무너지면 기록(전몰자 기록, 연대기)은 남고 폐허에서 재건합니다.

## 주의
- 모든 수치는 **임시 테스트 값**입니다(밸런스 미확정).
- 저장은 브라우저 localStorage 에만 됩니다(서버 검증 없음). 주소 뒤에 `?reset` 을 붙이면 저장이 지워집니다.
- 외부 세력, 파벌 갈등, 미형 생존자, 방어전, 서버 연동은 아직 구현 전입니다.

## 화면 구성

참고 시안(쉘터 단면 + 생존자 도감)을 따라 하단 원형 메뉴 5개: 탐험 / 쉘터 / 생존자 / 시스템(배급 정책·기록).
쉘터 화면은 상단 DAY·자원, 식량·식수·사기 게이지, 사다리가 있는 층 단면으로 이뤄집니다.

## 그림 교체 방법 (디자인은 나중에)

지금 화면은 임시 그림으로 연출만 맞춘 상태입니다. 그림은 파일만 바꿔 끼우면 됩니다.

- 방 그림: `public/assets/rooms/room-<시설id>.png` (같은 이름으로 덮어쓰기)
- 이름 있는 생존자: `public/assets/characters/<이름>.png`
- 일반(랜덤) 생존자 조합 파츠: `public/assets/parts/` — 규칙은 그 폴더의 `README.md` 참고.
  파츠를 넣고 `manifest.json` 의 숫자만 맞추면 자동으로 조합된 모습으로 바뀝니다.


## 유물 도감

생존자는 무작위로 나오므로 도감 대상이 아닙니다. 도감은 원정에서 아주 낮은 확률(기본 5% + 위험도/1000)로 나오는 유물(지역별 5개, 흔함·희귀·영웅·전설 25종)을 모읍니다. 처음 찾으면 고철 보너스, 중복은 소량 고철. 정착지가 붕괴해도 유지됩니다. 아이콘은 이모지 자리표시자이며 `RELICS`(src/sim/data.ts)의 `icon`을 그림으로 교체하면 됩니다.

## 캐릭터 그림 (현재 방식)

`public/assets/chars/atlas.png` 한 장에 남/여 × 앞·옆·뒤 × 5프레임이 들어 있고(`atlas.json` 에 칸 크기), 코드가 피부·머리·옷 색만 바꿔서 생존자마다 다르게 보여 줍니다. 같은 칸 구성으로 새 그림을 만들어 덮어쓰면 코드 수정 없이 교체됩니다. 시트의 머리 표정·모자·옷·가방·무기 등 나머지 부품은 `public/assets/sheet/parts_sheet.png` 와 `parts_boxes.json` 에 잘라 둔 상태로 보관 중입니다.

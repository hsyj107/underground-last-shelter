# UNDERGROUND: LAST SHELTER

좀비 아포칼립스 지하 벙커 생존 경영 시뮬레이션. 플레이어는 단말기 앞의 사령관이며, 자원과 사람을 통제합니다.
(TypeScript + Vite, 화면은 HTML 단말기 UI, 규칙은 `src/sim` 의 순수 시뮬레이션 엔진)

## 구조
- `src/sim` : 게임 규칙(하루 정산, 배급, 원정, 세럼 결정, 칭호 등). 화면과 무관하게 테스트 가능
- `src/ui` : CRT 단말기 화면
- `tools/tests/sim.test.ts` : 엔진 테스트

## 실행
```
npm install
npm run dev
```

## 시간
- 현실 시간이 흐르면 게임 하루가 자동으로 정산됩니다. (⚠ 임시: 현실 1시간 = 게임 1일)
- 접속하지 않은 동안은 최대 6일까지 한꺼번에 계산하고, 돌아오면 복귀 보고가 뜹니다.
- 시험하려면 주소 끝에 `?dayms=30000`(하루 30초)을 붙이거나, 화면 아래 "시험용" 버튼으로 하루를 즉시 넘깁니다.
- 정착지가 전멸하거나 폭동으로 무너지면 기록(전몰자 기록, 연대기)은 남고 폐허에서 재건합니다.

## 주의
- 모든 수치는 **임시 테스트 값**입니다(밸런스 미확정).
- 저장은 브라우저 localStorage 에만 됩니다(서버 검증 없음). 주소 뒤에 `?reset` 을 붙이면 저장이 지워집니다.
- 외부 세력, 파벌 갈등, 미형 생존자, 방어전, 서버 연동은 아직 구현 전입니다.

## 그림 교체 방법 (디자인은 나중에)

지금 화면은 임시 그림으로 연출만 맞춘 상태입니다. 그림은 파일만 바꿔 끼우면 됩니다.

- 방 그림: `public/assets/rooms/room-<시설id>.png` (같은 이름으로 덮어쓰기)
- 이름 있는 생존자: `public/assets/characters/<이름>.png`
- 일반(랜덤) 생존자 조합 파츠: `public/assets/parts/` — 규칙은 그 폴더의 `README.md` 참고.
  파츠를 넣고 `manifest.json` 의 숫자만 맞추면 자동으로 조합된 모습으로 바뀝니다.

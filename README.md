# 지하 7층의 종말 편의점

좀비 사태가 터진 폐허 도시의 지하 7층. 불이 꺼지지 않은 작은 편의점에 생존자들이 모여듭니다.
탐사대를 지상으로 보내 멸망 전 문명의 흔적(통조림, 건전지, 낡은 만화책…)을 주워 오고, 선반을 채우고, 개성 있는 생존자들을 맞이하는 **방치형 수집 게임**입니다.

(TypeScript + Vite, 화면은 캔버스 도트 장면 + HTML UI, 규칙은 `src/state.ts`)

## 게임 루프

디자인은 따뜻한 도트, 규칙은 하드코어입니다.

1. **비축과 소비** – 모두가 먹고 마십니다. 식량·식수는 벙커의 수경재배·정수 설비가 조금씩 만들고, 부족분은 탐사로 메웁니다. 접속을 꺼도 시간은 흐르고 비축은 줄어듭니다(최대 8시간~). 배급은 정상 / 절식 / 극한 절식 중에서 고릅니다. 줄이면 아끼지만 탐사 사망 확률이 오르고 호감을 얻기 어렵습니다.
2. **탐사** – 구역(슈퍼마트, 약국, 헌책방, 전자상가, 병원, 경찰서, 대형마트 지하)에 1~3명을 보냅니다. 식량·물·의약품과 수집품, 뚜껑(●)을 가져옵니다. 들키면 죽는 사람이 나올 수 있고, 죽은 사람은 돌아오지 않습니다(유언과 추모비가 남습니다). 사망 판정은 출발 시 확정되고 돌아와서 공개되므로 접속을 끈 사이 억울하게 죽지 않습니다.
3. **생존자** – 직업 8종에서 무작위로 나옵니다(이름·외형 무작위, 직업 핵심 능력치는 최소치 보장). 능력치는 전투·수색·의료·매력. 서로 친함/불화 관계가 있고, 친구가 죽으면 남은 사람이 흔들립니다. 대화·선물로 호감도를 올리면 3장짜리 이야기가 열립니다.
4. **굶주림 위기** – 식량·물이 오래 바닥나 있으면 "누구를 내보낼까 / 모두 굶고 버틸까" 선택이 닥칩니다.
5. **도감** – 물건 43종을 모으면 분류별 효과가 생깁니다(식료품: 식량 생산 +25%, 생활: 식수 +25%, 의약품: 탐사 사망 -10%, 전자: 탐사 시간 -10%, 문화: 대화 호감 +25%, 반려: 전리품 +1). 뚜껑은 개조에 씁니다.

생존자의 능력은 **벙커에 있을 때**(생산·의약품·절식 완화) 또는 **탐사대에 있을 때**(전리품·안전) 적용됩니다. 누구를 내보낼지가 선택입니다.

| 직업 | 한 줄 | 능력 |
|---|---|---|
| 식당 사장 | 전직 해장국집 사장 | 벙커: 식량 생산 +40% |
| 개발자 | 밤샘 코딩하던 개발자 | 벙커: 식수 생산 +40% |
| 특수부대 | 은퇴한 특수부대 원사 | 탐사: 들킬 확률 -60%, 전리품 +1 (전투 8~10) |
| 고양이 | 길고양이 | 탐사: 희귀·전설 확률 +80% |
| 간호사 | 종합병원 야간 간호사 | 벙커: 탐사 의약품 +40% (의료 7~10) |
| 만화방 주인 | 40년차 만화방 주인 | 벙커: 절식의 부작용 절반 |
| DJ | 심야 라디오 DJ | 벙커: 모든 생산 +10% (매력 7~10) |
| 아이 | 아홉 살 | 탐사: 전리품 +1, 새 발견 보너스 2배 |

## 구조

- `src/data.ts` : 물건, 구역(보급량 포함), 직업(이야기·유언 포함), 개조 데이터
- `src/state.ts` : 규칙(비축·소비, 배급, 탐사·사망, 관계, 위기, 저장). 화면과 무관하게 node 로 테스트 가능
- `src/shapes.ts`, `src/sprites.ts` : 코드로 그린 8x8 물건 아이콘, 생존자/좀비/고양이 도트
- `src/scene.ts` : 지상 + 지하 7층 편의점 단면 캔버스
- `src/ui.ts`, `src/style.css` : 탭(벙커/탐사/선반/생존자), 모달, 알림
- `tools/tests/logic.test.ts` : 규칙 테스트
- `legacy/` : 이전 방향(CRT 단말기 하드코어 생존 경영)의 그림 자산. 배포에는 포함되지 않음 (옛 코드는 git 기록에 남아 있음)

## 실행

```
npm install
npm run dev
npm test          # node 22.18+ (타입 제거 내장)
```

## 시험용

- 주소 끝에 `?speed=30` : 시간이 30배 빨라집니다 (탐사·방문자 등).
- 주소 끝에 `?reset` : 저장 삭제.
- 저장은 브라우저 localStorage 에만 됩니다.

## 그림 교체

지금 그림은 전부 코드로 그린 임시 도트입니다. 물건 모양은 `src/shapes.ts`(글자 8x8), 색은 `src/data.ts`의 팔레트, 사람은 `Look`(피부·머리·옷·장신구)으로 정해집니다.
나중에 그린 그림으로 바꿀 때는 `sprites.ts`의 `iconCanvas`/`drawPerson` 만 이미지 기반으로 교체하면 됩니다.

## 주의

- 모든 수치(생산·소비량, 사망 확률, 개조 비용, 탐사 시간)는 **시험용**입니다. 밸런스는 미확정입니다.
- 폰트는 Galmuri(CDN)를 쓰며, 불러오지 못하면 시스템 글꼴로 보입니다.
